## 简体中文

ES3 Studio 是一款在浏览器中运行的编辑器，用来制作 Malody V 的 Slide 皮肤 **Extra-Slide v3** 的扩展文件 `lane3d.ex`。
可以一边看时间轴和与游戏相同画面的 3D 预览，一边放置空中音符、描线、镜头演出和画面特效。

- 打开上面的网址即可使用，无需安装（推荐电脑版 Chrome / Edge）
- 谱面和文件不会被上传，所有处理都在你的电脑上完成
- [使用说明](docs/zh/index.md)

## 日本語

ES3 Studio は、Malody V の Slide 用スキン **Extra-Slide v3** の拡張ファイル `lane3d.ex` を作る、ブラウザで動くエディターです。
タイムラインと、ゲームと同じ見た目の 3D プレビューを見ながら、空中ノーツ・トレース・カメラ演出・画面演出を置けます。

- 上のアドレスを開けば、インストールなしで使えます（パソコンの Chrome / Edge を推奨）
- 譜面やファイルがどこかへ送られることはなく、すべてお使いのパソコンの中で動きます
- [使い方](docs/ja/index.md)

## English

ES3 Studio is a browser-based editor for `lane3d.ex`, the extension file of **Extra-Slide v3**, a Slide skin for Malody V.
Place air notes, traces, camera moves and screen effects on a timeline while watching a 3D preview that looks the same as the game.

- Open the address above; nothing to install (Chrome / Edge on a computer recommended)
- Your charts and files are never uploaded; everything runs on your computer
- [User guide](docs/en/index.md)
